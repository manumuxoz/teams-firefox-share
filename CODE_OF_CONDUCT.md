# Código de conducta

## Compromiso

Este proyecto quiere ser un espacio útil y respetuoso para personas con distintos niveles de experiencia, sistemas y opiniones técnicas. La crítica al código y a las decisiones técnicas es bienvenida; el desprecio a las personas no.

## Comportamiento esperado

- Discutir ideas y cambios con argumentos técnicos.
- Asumir buena fe y pedir contexto antes de acusar.
- Respetar que el proyecto no puede arreglar fallos de portal, compositor o de Microsoft Teams.
- Mantener los issues y PRs centrados en el proyecto.
- No publicar datos personales, tokens, IDs de reunión ni contenido de reuniones.

## Comportamiento inaceptable

- Acoso, insultos, amenazas o discriminación.
- Publicar información privada de terceros.
- Spam, suplantación o manipulación de issues.
- Presionar para que se acepten cambios que rompen la seguridad o la privacidad.

## Reporte

Si presencias o sufres una conducta inaceptable, contacta con el mantenedor a través de su perfil de GitHub. No publiques detalles sensibles ni datos personales de terceros en un issue.

Para vulnerabilidades de seguridad, usa [SECURITY.md](SECURITY.md), no un issue público.

## Consecuencias

El mantenedor puede editar o borrar comentarios, cerrar issues, rechazar PRs o bloquear temporalmente a una persona. La medida será proporcional al comportamiento y al impacto.
